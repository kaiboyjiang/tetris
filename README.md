# Tetris

A simple browser Tetris game in plain HTML, CSS, and JavaScript (no build step).

## Play

Open `index.html` in a browser, or visit the GitHub Pages deployment.

## Controls

| Key | Action |
| --- | --- |
| Left / Right | Move |
| Up | Rotate |
| Down | Soft drop |
| Space | Hard drop |
| P | Pause |
| Enter | Start / Restart |
